# 📘 Modul 1: Dasar Pemrograman Python untuk AI

Modul ini adalah titik awal bagi Zaki untuk memahami fondasi logika pemrograman Python yang dipakai dalam pengembangan Artificial Intelligence.

---

## 🎯 Tujuan Pembelajaran
Setelah menyelesaikan modul ini, Zaki akan mampu:
1. Memahami konsep **Variabel** dan **Tipe Data** dasar (`int`, `float`, `str`, `bool`).
2. Menerapkan logika percabangan **Kondisional** (`if - elif - else`) untuk sistem pakar (*rule-based system*).
3. Mengelola koleksi data menggunakan **List** dan **Dictionary** (struktur dasar dataset AI).
4. Melakukan **Looping (Perulangan)** untuk memproses data berulang dan menghitung statistik rata-rata evaluasi model.
5. Membuat **Fungsi (*Functions*)** untuk mensimulasikan prediksi kesehatan ekosistem lingkungan hidup.

---

## 🚀 Cara Menjalankan
Buka terminal (PowerShell atau Command Prompt) di folder ini, lalu jalankan:

```bash
python main.py
```
atau dari root direktori proyek:
```bash
python 01_dasar_python/main.py
```

---

## 💡 Konsep Penting AI pada Modul Ini
* **Mengapa Python?** Python memiliki sintaks yang menyerupai bahasa Inggris sederhana dan didukung oleh ekosistem library machine learning terbesar di dunia.
* **Logika Rule-based:** Sebelum deep learning populer, AI generasi pertama dibangun menggunakan aturan logika keputusan bertingkat (*decision logic*), yang kita simulasikan pada studi kasus Indeks Kualitas Udara (AQI) dan prediksi ekosistem laut.
